A beginners guide to Git and Github

Overview:
This is a project based tutorial to get started with code changes and project management by using Git and GitHub. It includes a crash course on git commands, branches, merging, pull requests, and collaboration.

Topics:
1. Git and Github basics
2. Version control and tracking changes
3. Commits and pushes
4. Branches and merging
5. Pull requests and code reviews
6. Project boards and Github issues

Project Plan:
See PLAN.md for the project plan

Goal:
To understand how developers use Git and Github to organize their work, save changes, and collaborate on projects
