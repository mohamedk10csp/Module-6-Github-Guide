Plan

A beginners guide to Git and Github

Goal: Make a simple guide that allows developers to understand how Git and Github can be used to keep track of changes and collaborate with others on projects

Guide: 

Section 1: Basics of Git and Github
1. What are Git and Github
2. Why is version control useful
3. Pushes and Git commits

Section 2: Branches and Merging 
1. Creating branches
2. Working on separate branches 
3. Merging changes into the Main branch

Section 3: Pull requests and Collaboration 
1. Creating pull requests
2. Reviewing changes
3. Github issues and Project boards

Tasks:
1. Write the introduction and Github basics
2. Explain branches, pull requests, and collaboration

Workflow:
1. Create repository and project plan
2. Create Github issues and Project board
3. Create branches for the assigned tasks
4. Commit and push changes
5. Review and merge pull requests
6. Practice resolving a merge conflict
7. Record a 5 minute project video
