Branches and Collaboration: 
Branches let developers to make changes without impacting the main version of a project. 
It comes in handy when features are added or problems solved. 

Merging: 
Merging is the process of taking changes from one branch and into another. 
After the changes have been completed and reviewed, they can be merged into the main branch. 

Pull Requests:
A Pull request is a proposal made by developers before merging changes on to the main branch. 
Other developers can see the changes, make comments and make suggestions. 

GitHub Collaboration Tools 
GitHub Issues help to track tasks and issues of a project.
Project Boards are a way of organizing those tasks and presenting what's done, what's ongoing, and what's finished.
