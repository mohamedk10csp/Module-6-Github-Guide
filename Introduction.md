
Introduction to Git and GitHub
What is Git and What is GitHub? 
Git is a version control system, which let's developers to monitor the changes to their files and projects. 
GitHub is an online service that provides developers with the ability to store their Git repositories and collaborate with others. 

What is the advantage of version control? 
Version control is a tool that helps in maintaining a record of the developers work. 
When something goes wrong, they have the option to go back to a past version. It also helps teams to collaborate on the same project.

Git Commits and Pushes
Committing is to save changes to the local Git repository. 
A push pushes the changes that have been committed on the local repository to the remote repository on GitHub. 
For example, a developer can modify a Python file, stage it with git add, commit the changes to the local repository with git commit and push the changes to GitHub with git push.
